## 5. 调用与接入方法

### 5.1 调用入口

- **当前方式**：人工加载（Agent负责人杨景凡直接读取Markdown内容）
- **未来方式**：通过 `knowledge.query` 工具检索

### 5.2 最小示例

```text
<脱敏请求/调用示例>

Agent输入事件 → 识别为WebShell场景 → 查找 webshell-knowledge.md → 
按关键词（如“攻击原理”“冰蝎流量特征”）匹配对应知识条目 → 将知识内容写入调查报告的证据和结论部分
```

```text
<脱敏响应/返回示例>

验证记录（杨景凡，2026-08-26）：
换 WebShell 变体（换 IP / 换管理工具 / 换漏洞）→ 会，且正确支撑

输入事件变化	查询词	命中
换攻击源/目标 IP、换漏洞	WebShell攻击原理	攻击原理
冰蝎代替菜刀	冰蝎流量特征	主流管理工具与流量特征
蚁剑	蚁剑流量特征	主流管理工具与流量特征

LLM 看到仍是 WebShell 事件 → 主动调 knowledge_query → 关键词命中正确条目 → 支撑结论（160036 那轮已实证）。
```

### 5.3 上下游接入注意事项

- 知识条目中的 `[引用来源：xxx]` 为人工标注的引用依据，用于支撑调查结论的可信度；
- Agent读取知识包时按关键词匹配，当前为静态读取，不涉及API调用；
