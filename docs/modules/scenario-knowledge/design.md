## 1. 目标与非目标

### 1.1 目标

- 为深度调查Agent提供WebShell场景的结构化安全知识支撑，涵盖攻击原理、调查要点、证据检查清单、处置建议、停止条件等核心知识维度；
- 提供5个知识问答样本，用于评测Agent知识检索与理解能力；

### 1.2 非目标

- 本模块不负责知识库的向量化存储和检索服务（由FastGPT/OpenClaw平台提供）

## 2. 职责与边界

- 本模块负责：WebShell场景安全知识的整理、结构化、来源标注和版本维护
- 本模块不负责：知识库平台搭建、向量检索服务、Agent推理逻辑
- 需要人工参与的环节：知识内容更新、来源核验、与Agent对接确认

## 3. 输入与输出

### 3.1 输入

| 字段/对象 | 类型 | 必填 | 来源 | 含义与约束 |
|---|---|---|---|---|
| 主场景 | 字符串 | 是 | 平台验证小组 | 当前固定为WebShell |
| 权威知识来源 | URL/文档 | 是 | MITRE/CISA/NSA等公开资料 | 须为可访问的官方来源 或 公认经验总结 |

### 3.2 输出

| 字段/对象 | 类型 | 去向 | 含义与约束 |
|---|---|---|---|
| webshell-knowledge.md  | Markdown文档 | 深度调查Agent / 知识库 | 结构化知识条目，含来源标注           |
| webshell-qa-samples.md | Markdown文档 | 评测组                 | 5个问答样本，含reference标注和索引表 |

## 4. 核心流程与状态变化

```json
1. 确认主场景（WebShell）和权威知识来源；
2. 从知识包目录中抽取Agent核心使用部分（攻击原理、调查要点、证据清单、处置建议、停止规则）；
3. 结构化整理为Markdown文档，标注引用来源；
4. 编制问答样本，与知识包内容对应；
5. 与深度调查Agent负责人确认内容可用性；
6. 按需更新版本。
```

## 6. 安全边界

- 权限与审批：知识材料不涉及敏感权限；内容修改通过PR评审流程
- 输入校验：来源链接须验证可访问
- 敏感信息处理：仅引用公开权威资料和公认经验数据，不包含内部凭据或脱敏数据
- 失败、超时与人工接管：知识检索失败时Agent应使用已有知识或标记“知识不可用”，不得编造
- 真实执行与Mock边界：当前为知识材料，不涉及真实执行或Mock

## 7. 关键设计决策

| 决策 | 原因 | 未采用方案及原因 |
|---|---|---|
| 仅覆盖WebShell单一场景 | MVP阶段聚焦可稳定复现的主场景 | 多场景覆盖会导致知识包范围过大，超出MVP边界 |
| 知识条目标注引用来源   | 确保可追溯、可验证，支撑比赛评测 | 无来源标注的知识无法证明可靠性 |
| 删除自定的输入输出字段 | 避免与后端模型冲突 | 维护第二套契约会导致Agent接入时字段对不上 |
| 问答样本独立于知识包 | 知识包供Agent检索，问答样本供评测 | 混在一起会导致职责不清 |
