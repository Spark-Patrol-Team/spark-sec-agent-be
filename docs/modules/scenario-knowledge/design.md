## 输入输出
## 1. 目标与非目标

- 输入：场景名称、事件摘要、证据缺口。
- 输出：知识引用、调查建议、处置建议。
### 1.1 目标

## 安全边界
- 为深度调查 Agent 提供 WebShell 场景的结构化安全知识材料，覆盖攻击原理、调查要点、证据检查清单、处置建议、停止条件和人工接管规则。
- 提供 5 个知识问答样本，用于后续评估知识检索与理解能力。
- 保留引用索引，便于后续逐条核验来源和维护知识版本。

- 不编造知识来源。
- 不把未经脱敏的平台原始内容写入知识库。
### 1.2 非目标

## 待补充
- 本模块不负责知识库平台、向量化存储或检索服务的搭建。
- 本 PR 不交付 Agent 运行时代码，也不证明知识材料已被 Agent 自动消费。
- 本 PR 不覆盖真实 XDR 数据接入或真实平台联调。

- 主场景最终确认。
- 知识包结构。
- RAG 或 FastGPT 知识库接入方式。
## 2. 职责与边界

- 本模块负责：WebShell 场景知识的整理、结构化、来源标注和版本维护。
- 本模块不负责：知识库平台、向量检索服务、Agent 推理逻辑及真实平台接口。
- 需要人工参与：来源逐条复核、知识内容更新、与 Agent 运行时的接入确认和功能复验。

### 3.1 输入

## 4. 核心流程

```text
确认 WebShell 场景与资料范围
  -> 整理攻击原理、调查要点、证据清单、处置建议和停止规则
  -> 形成结构化 Markdown 知识材料并标注引用
  -> 编制问答样本并建立参考资料索引
  -> 逐条复核来源与知识主张
  -> 由运行时负责人完成接入和功能复验
```

## 6. 安全边界

- 内容修改应通过 PR 评审并保留变更记录。
- 来源链接、出处与知识主张必须逐条核验；未经复核的内容不得标记为“已验收”。
- 知识检索失败或证据不足时，Agent 应明确标记知识不可用或触发人工接管，不得编造结果。
- 本模块只提供知识材料，不执行真实处置动作。

## 7. 关键设计决策

| 决策 | 原因 | 未采用方案及原因 |
|---|---|---|
| MVP 仅覆盖 WebShell 单一场景 | 聚焦可复现的主场景，控制交付范围 | 同时覆盖多场景会扩大知识维护和验证成本 |
| 知识材料与问答样本分文件维护 | 分离运行时知识和评测资产 | 混在同一文件中不利于职责划分和后续导入 |
| 保留引用索引 | 支持追溯和后续来源复核 | 无来源标注的知识难以审查 |
| 不在本 PR 定义第二套运行时接口 | 避免与目标主干的 Agent 契约冲突 | 自定义接口可能造成重复实现和字段不一致 |

## 8. 非功能、可观测与审计要求

| 维度 | 当前要求 | 验证方式 |
|---|---|---|
| 可读性 | Markdown 标题、表格、列表可正常渲染，无模板占位符 | Markdown 预览和静态检查 |
| 可重复性 | 同一版本材料内容固定，可通过 Commit 定位 | Git 版本记录 |
| 可追溯性 | 关键知识条目保留引用或资料索引 | 人工逐条核对 |
| 可观测性 | 运行时调用需由 Agent 侧记录查询词、命中内容和关联事件 | 待运行时复验 |
