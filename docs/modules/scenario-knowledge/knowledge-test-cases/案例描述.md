## 用例详细说明


### TC-KNOWLEDGE-001：IIS WebShell（UpdateChecker.aspx）

| 字段             | 内容                                                         |
| ---------------- | ------------------------------------------------------------ |
| **类别**         | 正向变体                                                     |
| **来源**         | https://www.fortinet.com/blog/threat-research/in-depth-analysis-of-an-obfuscated-web-shell-script  （FortiGuard Labs于2025年7月发布的分析报告） |
| **简介**         | FortiGuard Labs分析：UpdateChecker.aspx WebShell（2025），分析部署在Microsoft IIS服务器上的混淆WebShell，包括Unicode编码和加密混淆技术、JSON命令结构及三大模块功能 |
| **攻击特征**     | ASPX页面，Unicode编码+加密混淆；HTTP POST触发，请求头`application/octet-stream`；命令通过Base64编码的AES加密数据传递；支持信息收集、文件管理、命令执行三大模块 |
| **输入事件**     | 见 `case1.json`                                              |
| **预期查询词**   | `["WebShell攻击原理", "WebShell证据检查清单"]`               |
| **预期命中知识** | `webshell-knowledge.md §1.2 攻击原理`（WebShell定义与隐蔽通信特征）；`webshell-knowledge.md §3 Agent证据检查清单`（文件系统检查、Web日志异常请求检查） |
| **预期报告变化** | 确认攻击类型为WebShell；识别隐蔽通信技术（AES加密+C#编译）；置信度从0.76提升至≥0.85；攻击链：文件写入→加密HTTP通信→命令执行 |
| **禁止结论**     | 不得断言攻击者身份或归属；不得断言已定位C2服务器；不得在没有日志分析的情况下断言初始访问路径 |



### TC-KNOWLEDGE-002：Godzilla WebShell（PassiveNeuron活动）

| 字段             | 内容                                                         |
| ---------------- | ------------------------------------------------------------ |
| **类别**         | 正向变体                                                     |
| **来源**         | https://securelist.com/passiveneuron-campaign-with-apt-implants-and-cobalt-strike/117745/ （卡巴斯基官方研究团队（GReAT）发布详细技术报告的网站） |
| **简介**         | PassiveNeuron间谍活动（2025）：利用暴露的ASP.NET MachineKey部署Godzilla WebShell；卡巴斯基于2024年底首次发现，主要针对亚洲、非洲和拉丁美洲的政府、金融和工业部门 |
| **攻击特征**     | 利用暴露/重复使用的MachineKey（ValidationKey/DecryptionKey）通过`_VIEWSTATE`反序列化执行任意命令；部署Godzilla家族WebShell（1.aspx）；进一步部署TOLLBOOTH持久化模块和内核驱动Rootkit隐藏痕迹 |
| **输入事件**     | 见 `case2.json`                                              |
| **预期查询词**   | `["哥斯拉 流量特征", "WebShell隐蔽与免杀技术"]`              |
| **预期命中知识** | `webshell-knowledge.md §2.2 主流管理工具与流量特征（哥斯拉行）`（AES/RSA强加密、分块传输特征）；`webshell-knowledge.md §2.5 隐蔽与免杀技术`（暂未写入最小知识包） |
| **预期报告变化** | 识别WebShell类型为Godzilla家族；标注高级隐蔽技术（内核驱动隐藏、进程隐藏）；置信度≥0.88；建议立即检查MachineKey配置和持久化模块 |
| **禁止结论**     | 不得断言攻击者身份为特定APT组织；不得断言已完全清除后门      |



### TC-KNOWLEDGE-003：Beima WebShell（WordPress/cPanel）

| 字段             | 内容                                                         |
| ---------------- | ------------------------------------------------------------ |
| **类别**         | 正向变体                                                     |
| **来源**         | https://www.mallory.ai/malware/019ae9cf-0b2c-7e45-969a-38c841c46661 （Mallory.ai恶意软件分析页面，收录了Cyderes Howler Cell团队于2025年4月发布的Beima PHP WebShell分析报告） |
| **简介**         | Cyderes调查：Beima WebShell（2025），感染超过80个WordPress和cPanel服务器 |
| **攻击特征**     | 此前未被记录的PHP WebShell；仅接受使用硬编码RSA密钥解密的加密命令；通过JSON格式与攻击者面板通信，伪装成正常API流量；可上传恶意载荷、窃取数据、执行命令；通过修改文件时间戳规避检测；针对配置错误的WordPress和cPanel环境 |
| **输入事件**     | 见`case3.json`                                               |
| **预期查询词**   | `["WebShell攻击原理", "WebShell证据检查清单"]`               |
| **预期命中知识** | `webshell-knowledge.md §1.2 攻击原理`（WebShell定义）；`webshell-knowledge.md §3 Agent证据检查清单`第1、2、5项（文件系统检查、时间戳异常、网络连接监控） |
| **预期报告变化** | 确认攻击类型为WebShell；识别RSA加密通信和JSON伪装技术；置信度从0.72提升至≥0.82；建议立即隔离服务器并检查.htaccess和上传目录 |
| **禁止结论**     | 不得断言攻击者归属（Beima关联的运营商身份未经官方确认）；不得断言数据已被窃取 |

## 执行说明

- **运行方式**：将 `case1~6.json`  逐个传入Agent，观察Agent是否返回结果以及返回的知识是否被正确j检索或写入调查报告。
- **判断标准**：
  - **正向变体（TC-001~003）**：预期查询词命中目标知识条目（检索通过），且知识被正确写入报告（Agent实际消费），视为"通过"
  - **证据不足（TC-004~005）**：Agent输出"证据不足/需要人工接管"视为"通过"
  - **对照案例（TC-006）**：不命中任何WebShell知识，且不将事件误判为WebShell视为"通过"
- **注意事项**：对照案例不得将非WebShell事件误判为WebShell；证据不足案例不得编造结论；正向变体中"检索通过"和"Agent实际消费"两个环节均需验证
