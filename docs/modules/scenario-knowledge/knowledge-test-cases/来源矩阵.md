## Review要求

1. 来源支持“某公开事件曾出现某技术”，不等于支持synthetic JSON中的每个字段。
2. Agent可以复述输入明确给出的信号，并用知识包给出调查方向；不得把一般知识升级为本事件已发生的事实。
3. TC-003和TC-006当前来源级别较弱；未补到原始研究前，只保留保守的评测主张。
4. 该矩阵由钱诺成Review事实与表述；任何新增精确事实须同时补直接来源。
