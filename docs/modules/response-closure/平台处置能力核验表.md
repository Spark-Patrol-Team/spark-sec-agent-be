# 平台处置能力核验表

## 一、核验目标

本文档对应 `T0827-08 肖迎春：平台处置能力核验与 Mock 安全边界` 第一项任务，用于基于企业材料、《平台定向验证统一结论》、XDR 官方用户手册以及当前平台实机核验结果，建立“平台处置能力核验表”。

本表仅记录当前阶段已经确认的能力边界，不发起真实封禁、隔离、查杀、拦截等会改变真实安全状态的操作。没有实测证据的项目统一标记为“产品材料存在，当前环境未验证”或“待确认”。

本表不把产品材料、页面入口、账号权限、平台记录和设备生效视为同一层级。每项能力应分别判断：是否能看到入口，是否能确认资源和权限，是否产生平台记录，是否有独立证据证明真实设备状态改变，以及当前是否存在外部阻塞。

## 二、证据分层与结论口径

| 层级 | 可支持的结论 | 不能直接推出的结论 |
| --- | --- | --- |
| `L0` 可见能力 | 页面、列表、详情、日志或动作目录可访问 | 真实接口可调用、动作已执行或设备已生效 |
| `Mock` | 本地有状态 Mock、审批、幂等和独立验证流程可回归 | XDR 真实动作、真实设备联动或真实平台生效 |
| `平台记录` | 平台产生执行记录、审批记录、审计日志或动作回执 | 网络、主机、文件或进程状态已经改变 |
| `设备生效` | 有授权测试对象和独立验证证据证明真实状态变化 | 可将单个对象结果扩展为批量或全局能力 |
| `外部阻塞` | 真实接口、设备资源、授权对象或验证条件缺失 | 仅凭产品材料或页面入口认定真实处置可用 |

后文中的“已确认”应注明对应层级；无法达到“设备生效”层级时，统一使用“当前未验证”“待确认”或“无法确认”。
