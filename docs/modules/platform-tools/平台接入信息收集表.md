# 平台接入信息收集表（MCP / 真实 Agent）

> 用途：收齐**真实 MCP 工具**与**真实 Agent / FastGPT / 远程 Agent** 接入所需的外部输入，用于补齐主链 P0（真实 MCP 调查闭环、真实 Agent Bridge）。
> 填写方：平台 / 网络 / 安全对接人复核后填写。
> **安全约定**：本表只登记“是否已提供”与“注入位置”；真实地址、Token、AK/SK、联动码、Cookie、账号密码**禁止写入本文件或任何评审材料**，真实值一律通过本机 `.env` 或密钥系统注入。

## 0. 填写须知

- ⭐ = 阻塞项，缺该项无法实机联调。
- “仓库已定义、无需你提供”的项见文末【附：仓库已定义（确认即可）】。
- 变量名（`MCP_URLS`、`MCP_API_KEY` 等）见 `.env.example` 与本文括注。

## 附：仓库已定义（确认即可，无需你提供）

- MCP 传输：HTTP + SSE，JSON-RPC 2.0；会话 `Mcp-Session-Id`。
- MCP 鉴权：`Authorization: Bearer` + `apikey`。
- MCP 工具拉取：`tools/list` 自动获取 `name / description / inputSchema`。
- 调查 Agent 输入契约：`SecurityEventInput`（10 字段 + `triage` + `trace_id / run_id`）。
- 调查 Agent 输出契约：`InvestigationReport`（12 项，与清单字段基本一致）。
- 失败 / 降级：接入失败 → `FAILED`；调查证据不足 → 人工接管；远程 Agent 不可用可回退内部子链。
- 已知工具清单：19 个（中文名 → 内部别名映射）。
- 既有超时默认：LLM 90s、XDR connect 5s / read 30s、MCP 20s。
